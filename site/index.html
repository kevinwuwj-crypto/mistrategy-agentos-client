MIStrategy

此站点托管 MIStrategy 的公开 OAuth 客户端描述文件，供 Binance Agent OS 在用户登录授权时识别客户端。

授权回调目标为本机地址 http://127.0.0.1:43872/oauth/callback。此站点没有登录表单，不接收授权回调，也不存放访问令牌、账户记录或策略数据。

连接 Binance 与批准某个策略版本是两个步骤。发布这份描述文件不会授权策略或发出交易订单。

MIStrategy 是独立客户端，并非 Binance 官方产品。
